# Phase 1.1: Extraction - Design (short)

**Intent:** reliably pull every open posting for a watch-list of AI/tech companies from their
ATS, politely and defensively, so Phase 1.2 can store snapshots and later phases can detect
hiring anomalies. First source: Greenhouse public board API.

**User direction (2026-10-31):** (1) `ATSSource` base interface, (2) shared HTTP client with
strict rate limiting, retries and exponential backoff, (3) Greenhouse scraper on
`boards-api.greenhouse.io`. Seed companies: OpenAI, Anthropic, Databricks, Stripe.

## Live findings (probed 2026-10-31, one GET each)
| Board token | Greenhouse | Jobs |
|---|---|---|
| `anthropic` | 200 | 675 |
| `databricks` | 200 | 901 |
| `stripe` | 200 | 746 |
| `openai` | **404** - OpenAI uses Ashby (`api.ashbyhq.com/posting-api/job-board/openai` → 200) | - |

- `GET /v1/boards/{token}/jobs` → `{"jobs": [...], "meta": {"total": N}}`; job keys:
  `id, title, location{name}, absolute_url, first_published, updated_at, company_name,
  requisition_id, internal_job_id, metadata, language, ...` - **no departments**.
- `?content=true` adds `departments`, `offices`, HTML `content` → **9.8 MB** for Anthropic.
- `GET /v1/boards/{token}/departments` → `{"departments": [{id, name, parent_id, child_ids,
  jobs: [<same job object>]}]}` → **485 KB**, job count matches `/jobs` (675).
- Unknown board → 404. No rate-limit or Retry-After headers observed; `cache-control: max-age=0`.
- Timestamps are ISO-8601 with offset (`2026-10-19T11:17:24-04:00`). `location.name` can hold
  several places (`"San Francisco, CA | Seattle, WA"`) - splitting is Phase 1.3's job.

## Approaches (endpoint)
1. **`/departments` (chosen, assistant's call)** - one request per company, gives department
   (strong signal for role classification), same size as `/jobs`.
2. `/jobs` - same size, but loses department.
3. `/jobs?content=true` - department + offices, but ~20x larger; descriptions are not needed yet.

## Decisions (assistant's calls - flag any to change)
- HTTP library: **httpx** (sync; `MockTransport` gives network-free tests with no extra
  dependency). playwright stays deferred: Greenhouse needs no browser.
- Politeness defaults: 1 request / 2 s per host; 4 attempts max; backoff 1 s × 2ⁿ with full
  jitter, capped at 30 s; `Retry-After` (seconds) honoured but capped at 30 s; timeouts
  connect 5 s / read 20 s; 10 MB response cap; identifying User-Agent with the repo URL.
- Retry on 429, 500, 502, 503, 504 and transport errors/timeouts; never on other 4xx.
- Board tokens validated (`^[a-z0-9][a-z0-9_-]{0,63}$`) before any request: no path injection.
- A job listed under two departments is kept once (first department wins).
- One malformed job is skipped with a WARNING; a malformed top-level payload raises.
- OpenAI → an `AshbySource` as a follow-up task after Greenhouse (same interface).
- Output of Phase 1.1 is in-memory `Posting` objects + a CLI that writes JSON Lines to
  `data/raw/` (git-ignored); database persistence is Phase 1.2.
