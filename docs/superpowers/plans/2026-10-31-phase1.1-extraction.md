# Phase 1.1: Extraction (Greenhouse) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fetch every open posting for a list of Greenhouse board tokens through a polite, hardened HTTP client, returning validated `Posting` objects.

**Architecture:** `GreenhouseSource` implements the `ATSSource` interface and gets its data through a shared `HttpClient`. That client owns rate limiting, retries/backoff, timeouts, the size cap and error mapping. Sources only parse. All time and randomness (clock, sleep, jitter) are injected, so tests run instantly and give the same result every time. Network access in tests goes through `httpx.MockTransport` and recorded fixtures.

**Tech Stack:** Python 3.12, httpx, pydantic v2, pytest, uv, ruff.

**Spec:** `docs/superpowers/specs/2026-10-31-phase1.1-extraction-design.md`

## Global Constraints

- Python `>=3.12,<3.13`; run everything via `uv run ...`; add deps with `uv add`.
- Only new runtime dependency: `httpx`. No playwright, no respx.
- No live network in `tests/`; live calls only in Task 6's manual smoke step.
- Every file read/write in code and scripts passes `encoding="utf-8"`.
- Modules log via `logging.getLogger(__name__)`. INFO = run lifecycle, WARNING = retry/skip, ERROR = gave up.
- Politeness defaults: `min_interval=2.0`s per host, `max_attempts=4`, `backoff_base=1.0`, `backoff_cap=30.0`, timeouts connect 5 s / read 20 s, `max_response_bytes=10_000_000`.
- User-Agent: `JobSignal/0.1 (+https://github.com/LionyRamli/JobSignal; academic research)`.
- Gates per task: `uv run ruff check .`, `uv run ruff format --check .`, `uv run pytest` all exit 0.

## Review Focus

1. **Hostile board token** (`"../admin"`, `"stripe/jobs?x=1"`, `""`, `"Stripe "`) → `ValueError` before any HTTP request is made. *(Task 5: `test_invalid_board_token_rejected_without_request`)*
2. **Huge or odd `Retry-After`** (`3600`, an HTTP-date, `"-5"`) → the wait is capped at 30 s or falls back to computed backoff; we never sleep for an hour. *(Task 3: `test_retry_after_is_capped`, `test_unparseable_retry_after_falls_back_to_backoff`)*
3. **200 response that isn't JSON** (an HTML maintenance page) → `InvalidPayloadError`, not a crash. *(Task 3: `test_non_json_200_raises_invalid_payload`)*
4. **One bad job in an otherwise good board** (missing `title`) → that job is skipped with a WARNING and the rest are returned. *(Task 5: `test_malformed_job_is_skipped_with_warning`)*
5. **Job listed under two departments / empty board** → returned once; an empty board returns `[]`, not an error. *(Task 5: `test_job_in_two_departments_returned_once`, `test_empty_board_returns_empty_list`)*

### Task 3: Hardened HTTP client (retries, backoff, Retry-After, limits)

**Files:**
- Create: `src/jobsignal/extraction/http_client.py`
- Test: `tests/unit/extraction/test_http_client.py`

**Interfaces:**
- Consumes: `RateLimiter` (Task 2); errors (Task 1).
- Produces:
  - `RETRYABLE_STATUSES = frozenset({429, 500, 502, 503, 504})`, `USER_AGENT` (exact string from Global Constraints).
  - `class HttpClient(transport: httpx.BaseTransport | None = None, rate_limiter: RateLimiter | None = None, max_attempts: int = 4, backoff_base: float = 1.0, backoff_cap: float = 30.0, max_response_bytes: int = 10_000_000, sleep: Callable[[float], None] = time.sleep, rand: Callable[[], float] = random.random)`. Default rate limiter is `RateLimiter(2.0)`. It's a context manager (`close()` closes the httpx client).
  - `get_json(url: str, params: dict[str, str] | None = None) -> Any`.
- Behaviour:
  - Only `https://` URLs; anything else raises `ValueError`.
  - `rate_limiter.wait(host)` is called before **every** attempt, including retries.
  - 404 → `SourceNotFoundError`. Any other 4xx except 429 → `ExtractionError` straight away, with no retry.
  - Retryable status, `httpx.TransportError` or `httpx.TimeoutException` → sleep, then retry. Once `max_attempts` is used up → `RetryExhaustedError(last_status)`.
  - Backoff delay for attempt n (0-based): `rand() * min(backoff_cap, backoff_base * 2**n)` (full jitter). If `Retry-After` is a non-negative integer, use `min(that, backoff_cap)` instead.
  - Size cap: stream the body and raise `ResponseTooLargeError` as soon as it passes the limit (don't trust `Content-Length` alone).
  - JSON decode failure → `InvalidPayloadError`.
  - Logging: WARNING per retry (`url`, status/exception, delay, attempt n/max); ERROR when retries run out.

- [ ] **Step 1: Write the failing tests.** Build each client with `httpx.MockTransport(handler)`, a handler that returns scripted responses in order and counts calls, `RateLimiter(0)`, a recording `sleep` and `rand=lambda: 1.0`.
  - `test_returns_parsed_json_and_sends_user_agent`: handler checks `request.headers["User-Agent"] == USER_AGENT`.
  - `test_retries_503_then_succeeds_with_exponential_delays`: [503, 503, 200] → result OK, `sleeps == [1.0, 2.0]`.
  - `test_backoff_is_capped`: `backoff_cap=3`, five 503s with `max_attempts=5` → `sleeps == [1.0, 2.0, 3.0, 3.0]`, then `RetryExhaustedError` with `last_status == 503`.
  - `test_retry_after_is_honoured`: 429 with `Retry-After: 7` then 200 → `sleeps == [7.0]`.
  - `test_retry_after_is_capped`: `Retry-After: 3600` → `sleeps == [30.0]`.
  - `test_unparseable_retry_after_falls_back_to_backoff`: `Retry-After: Wed, 21 Oct 2026 07:28:00 GMT` → `sleeps == [1.0]`.
  - `test_transport_error_is_retried`: the handler raises `httpx.ConnectError` once, then returns 200 → succeeds; 2 calls.
  - `test_404_raises_source_not_found_without_retry`: 1 call, `sleeps == []`.
  - `test_400_is_not_retried`: 1 call, raises `ExtractionError` (and it is not a `RetryExhaustedError`).
  - `test_non_json_200_raises_invalid_payload`: body `"<html>Maintenance</html>"`.
  - `test_oversized_body_rejected`: `max_response_bytes=100`, 1 000-byte body with no `Content-Length` → `ResponseTooLargeError`.
  - `test_non_https_url_rejected`: `http://…` → `ValueError`, 0 calls.
  - `test_rate_limiter_consulted_on_every_attempt`: spy limiter; [503, 200] → `waits == ["boards-api.greenhouse.io"] * 2`.
  - `test_retry_logs_warning_and_exhaustion_logs_error` (caplog on `jobsignal.extraction.http_client`; set `propagate=True` in the test because `setup_logging` isn't called here).
- [ ] **Step 2: Run** `uv run pytest tests/unit/extraction/test_http_client.py -q` → FAIL (`ModuleNotFoundError`).
- [ ] **Step 3: Implement `HttpClient`.** Use `httpx.Client(transport=..., timeout=httpx.Timeout(20.0, connect=5.0), headers={"User-Agent": USER_AGENT}, follow_redirects=False)` and `client.stream("GET", ...)` with `iter_bytes()` to enforce the size cap.
- [ ] **Step 4: Run** → PASS; gates. Mutation-check the 404 branch, the cap and the jitter term (`mutate-check.sh`).
- [ ] **Step 5: Commit** `feat(extraction): add rate-limited HTTP client with retries and backoff`
